绘图工作台 · 本地 ComfyUI 提示词工作台
========================================
纯vibecoding造轮子的产物，功能基本comfyui自己都带，不过有个自己的前端界面，比看comfyui顺眼一点。
========================================
在浏览器里写提示词、管词库、配预设，一键把工作流提交给本机 ComfyUI 出图。

前端是零构建的原生 HTML/CSS/JS，没有框架、没有 npm、没有打包器；后端只有一个
几百行的 Python 标准库脚本，负责静态托管和同源反向代理。


特性
----

* **提示词工作台**：结构化录入角色 / 服装 / 场景 / 镜头 / 动作，实时拼成单行提示词，
  可复制或直接送进工作流。
* **本地词库**：标签库、组合模板、角色库、姿势库，支持搜索、点选、组合。
* **预设管理**：接口预设、上下文预设、生图预设各存一份，一键切换，可导入导出。
* **直接出图**：页面同源反代到本机 ComfyUI，提交工作流、轮询进度、读回成品。
* **历史回填**：按会话或按磁盘目录浏览成品，一键回填提示词与参数。
* **零构建**：改完 ``app.js`` 硬刷新即生效，不需要编译或安装依赖。


快速开始
--------

需要 Python 3.9+，以及已在本机运行起来的 ComfyUI（默认 ``127.0.0.1:8188``）。

::

    # Windows 直接双击
    启动工作台.bat

    # 或手动
    python tools/cors_proxy.py 8199 --open

浏览器打开 http://127.0.0.1:8199/ 即为工作台本体。

``启动工作台.bat`` 会优先使用本机已有的 ComfyUI Python，路径不存在时回退到系统
``python``，换一台机器不用改脚本。


目录结构
--------

::

    index.html  app.js  app.css     唯一真身：界面 / 逻辑 / 样式
    启动工作台.bat                   启动入口（静态托管 + 反代 + 自动开浏览器）
    data/                           自动生成的词库（tags / templates / presets / characters …）
    tools/build_*.py                词库数据管线：改词库改这里，不要手改 data/*.js
    tools/zhsrc  tools/mosssrc      词库源数据（角色、版权、中文 tag 映射）
    tools/cors_proxy.py             本地服务
    使用说明.txt                     操作说明与常见问题


数据与隐私
----------

* 所有配置（预设、接口 Key、上下文配置）存在浏览器 ``localStorage``，不入库、不上传。
* 前端只与本机 ``127.0.0.1`` 通信；除你自己填的外部模型接口地址外，不向任何第三方发数据。
* 仓库里不含任何密钥。

详细操作说明见 `使用说明.txt <使用说明.txt>`_ 。
