绘图工作台 · 使用说明
======================================================================

在浏览器里写提示词、管词库、配预设，一键把工作流提交给本机 ComfyUI 出图。
前端是零构建的原生 HTML/CSS/JS（无框架、无 npm）；后端只有一个 Python 标准库
脚本，负责静态托管和同源反向代理。

----------------------------------------------------------------------
一、准备
----------------------------------------------------------------------
1. Python 3.9 或更高版本。
2. ComfyUI 已在本机运行，默认地址 127.0.0.1:8188。
3. Chrome / Edge 等现代浏览器。

不需要 npm、不需要打包、不需要联网装依赖。

----------------------------------------------------------------------
二、启动
----------------------------------------------------------------------
双击  启动工作台.bat ，浏览器会自动打开  http://127.0.0.1:8199/

也可以手动启动：

    python tools/cors_proxy.py 8199 --open

关掉那个命令行窗口，服务就停了。

端口分工：
    8199      页面本身
    /comfy/*  转发到 127.0.0.1:8188（提交工作流、取进度、读图片）
    /relay/*  通用直通，把请求转给 X-Relay-Target 头里的地址

因为页面和接口同源，浏览器的跨域检查不参与，ComfyUI 不用改任何启动参数。

----------------------------------------------------------------------
三、第一次使用
----------------------------------------------------------------------
1. 看右上角。显示「ComfyUI 已连接」就绪，底模下拉会自动列出模型。
   显示「未连接」时点它，面板会做一次诊断，选「改用本地服务 8199」即可。

2. （可选）右上「设置」→「AI 选词接口」，填接口地址、模型名、API Key，
   点「测试连接」看到回复就是通的。不配也能用，只是提示词要自己写。

3. 左栏「出图参数」选底模、尺寸、步数；需要多套配置时在
   「ComfyUI 生图配置」里新建或切换预设。

配置全部存在浏览器本地，关页面不丢，换浏览器或清缓存才会丢。

----------------------------------------------------------------------
四、日常流程
----------------------------------------------------------------------
   左栏写需求 → 「生成提示词」 → 右栏出结果 → 检查/微调 → 「出图」

· 生成提示词：把需求交给语言模型，产出正向标签、负面标签和正文。
· 出图：把右侧最终提示词连同生图参数提交给 ComfyUI。
· 选词 + 出图：两步合成一步，适合已经调好参数的日常批量。
· 追问：基于当前结果说一句「改成夜景」，需求跟着改，不用重写。
· 同步提示词：把右栏最终串读进生图参数，避免两边不一致。
· 种子锁 / 骰子：锁住 seed 只改标签，用来对比改动效果。
· 随机组合出图：随机角色 × 随机模板，用来找方向。

右侧栏顶部四个页签

    词库   标签库 / MOSS 词库 / 体位库，点条目加进当前栏位
    模板   组合模板与风格预设，一键套用
    角色   角色库搜索；「锁定角色」后每次生成都会带上
    日志   发出去的请求和收到的原文，排查「词为什么不对」看这里

----------------------------------------------------------------------
五、出图与历史
----------------------------------------------------------------------
· 出图后进度与缩略图在右栏底部，点开可看大图和回填。
· 「本次历史」记这一轮出过的图；「历史文件」按日期读磁盘上的成品目录。
· 「设置 → 图片保存」可以指定自己的保存目录，出图后由本地服务按日期
  分子目录另存一份；不填就只留在 ComfyUI 的 output 里。

----------------------------------------------------------------------
六、配置与数据
----------------------------------------------------------------------
· 接口预设、上下文预设、生图预设各存一份在浏览器 localStorage。
· 设置里提供导入 / 导出，用来换机器或备份。导出的接口预设含 Key 明文，
  只在自己设备之间传。
· data/*.js 是词库数据，由 tools/build_*.py 生成；重跑脚本会整份覆盖，
  不要手改。要改词库就改 tools/ 下的源数据与脚本。
· 仓库里不含任何密钥。

----------------------------------------------------------------------
七、目录
----------------------------------------------------------------------
    index.html  app.js  app.css   界面 / 逻辑 / 样式（唯一真身）
    启动工作台.bat                 启动入口：起服务并打开浏览器
    data/                         词库数据（生成的，勿手改）
    tools/build_*.py              词库生成脚本
    tools/zhsrc  tools/mosssrc    词库源数据
    tools/cors_proxy.py           本地服务：静态托管 + 反代
    tools/启动代理.bat             兼容入口，与根目录脚本等价

----------------------------------------------------------------------
八、常见问题
----------------------------------------------------------------------
页面打不开
    8199 被占用。关掉旧的命令行窗口，或换端口：
    python tools/cors_proxy.py 8200 --open

右上角显示未连接
    先确认 ComfyUI 在 8188 上跑着；再点那个指示灯，按诊断结果选
    「改用本地服务 8199」。它能区分「服务没开」和「被 CORS 拦」。

改了 cors_proxy.py 没生效
    必须重启「启动工作台.bat」，旧进程还在跑旧代码。

改了 app.js / index.html 没生效
    浏览器 Ctrl+F5 硬刷新。

出图一直转圈
    看「日志」页签和浏览器控制台；ComfyUI 那边窗口会打印缺节点、
    缺模型的具体名字，装好再重试。

端口能通但列表是空的
    点底模下拉右边的刷新按钮；仍为空说明 ComfyUI 的模型目录没有
    可用底模。
